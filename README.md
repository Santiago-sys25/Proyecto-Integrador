# Proyecto-Integrador
En este git, se presentan 2 archivos, siendo el de recomendaciones, el prototipo de recomendaciones.
Este funciona mediante un menu por numeros, siendo la opcion 1 la que permite introducir un prespuesto
para armar un nuevo PC, la opcion 2 permite actualizar los componentes y la 3 permite obtener un diagnostico sobre un problema.

El archivo algoritmo, representa un algoritmo general del sistema, lo coloque aqui para mostrar el resto del diagrama de flujo
